# sendspin-cpp-cli-nix

Nix flake for [sendspin-cpp-cli](https://github.com/Sendspin/sendspin-cpp-cli) — a headless Sendspin audio player.

## Usage

```sh
nix run . -- --help
nix run . -- --version
```
